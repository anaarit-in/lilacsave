# LilacSave 2.0 Professional release notes

- Added ranked advanced search, operators, date filters, recent searches, sorting, result counts, syntax feedback, and smart views.
- Added local smart tagging providers, custom keyword rules, normalized tag relations, tag administration, and bulk tagging.
- Added configurable Markdown, JSON, CSV, ZIP, and Google Drive exports.
- Added nested collections, bulk item actions, duplicate URL detection, and accessible keyboard alternatives.
- Added integrity-checked full backups, previewed merge/missing/replace restore, safety backups, backup history, and scheduled retention.
- Added actual Chrome shortcut discovery and selection capture on explicit command.
- Added schema-v3 migration while preserving V1 IDs, Drive references, sync queue state, and user content.

Live OAuth, Drive quota/rate-limit behavior, multi-device conflict scenarios, and Chrome Web Store review still require manual testing with the production Google Cloud project.
