# LilacSave 2.0 Professional user guide

## Search

Press Ctrl/Cmd+K in the dashboard. Combine ordinary words, quoted phrases, and operators: `type:bookmark`, `type:note`, `type:highlight`, `tag:research`, `domain:github.com`, `collection:technology`, `is:favorite`, `before:YYYY-MM-DD`, and `after:YYYY-MM-DD`. Invalid syntax appears beneath the search box.

## Organize

Use Collections to create nested folders. Drag one collection onto another or use its parent selector. Select visible items to move, tag, favorite, archive, delete, or export them. Smart Views finds recent, updated, untagged, unorganized, pending, archived, and duplicate-URL records. Duplicates are never deleted automatically.

## Notes Studio

Open **Notes** from the dashboard navigation for a writing-focused workspace with favorite, Markdown, and recent-update summaries. Select a note to read its full details, or use the card edit action for the focused editor. The editor supports title, content, collection, tags, and Markdown mode; updates are committed locally before entering the Drive sync queue.

## Smart tags and exports

Quick Save shows local suggestions that can be accepted, rejected, or disabled. Create domain, title, or content rules in Professional settings. Exports support combined Markdown, individual Markdown files in ZIP, JSON, CSV, and Markdown saved to `Lilac Save/Exports/` in Google Drive.

## Backups

Create a manual Drive backup or enable daily scheduled backups. Restore previews show new, newer, and unchanged records. Merge keeps newer records, Missing only adds absent IDs, and Replace makes a safety backup before replacing local records.

## Shortcuts

Settings shows Chrome's actual assigned shortcuts and links to `chrome://extensions/shortcuts`. Dashboard shortcuts do not run while typing: Ctrl/Cmd+K focuses search, Ctrl/Cmd+Alt+N creates a note, F favorites a selected item, Enter opens it, and Esc clears selection.
